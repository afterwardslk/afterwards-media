# Afterwards media

Public graphics and videos for Afterwards (myafterwards.com) social posts. Buffer reads post media from here.

Only content that is published publicly goes in this repository. Never add student data, enquiries, contracts, keys or passwords.

- `social/` post graphics (1080x1440 feed posts, 1080x1920 reels), one folder per batch
- `music/` original music written for Afterwards reels (no third-party audio)

## Rules (this repository is public)
- Only finished graphics, videos and music that are published on social media.
- Mock-ups use made-up names and grades. Never a real student's name, grades, phone, email or results slip.
- No screenshots of the admin page, Supabase, Buffer, emails or WhatsApp chats.
- No CSV, spreadsheet, PDF or text files. `.gitignore` only allows jpg, png, mp4 and mp3.
- If something private is ever pushed by mistake, deleting it is not enough (it stays in history): tell Claude right away so the repository can be wiped and recreated.
