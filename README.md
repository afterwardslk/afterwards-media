# Afterwards media

Public graphics and videos for Afterwards (myafterwards.com) social posts. Buffer reads post media from here.

Only content that is published publicly goes in this repository. Never add student data, enquiries, contracts, keys or passwords.

- `social/` post graphics (1080x1440 feed posts, 1080x1920 reels), one folder per batch
- `music/` original music written for Afterwards reels (no third-party audio)
